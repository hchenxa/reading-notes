# TLS 学习笔记

TLS / mTLS / 证书管理主题笔记。本目录收录一个四篇系列,从"代理与握手"讲起,一路到服务间双向认证与证书全生命周期,建议按 ①→④ 顺序阅读。

## 知识地图

```
① 正向 / 反向代理              为什么要有个"中间人"?(概念地基)
        │ 中间人撞上加密流量 → 握手在哪结束?私钥归谁?
        ▼
② 代理 × TLS:终结·透传·桥接    握手 / 密钥交换 / TLS 1.2 vs 1.3 / 攻防 / 抓包
        │ 只验服务器不够 → 服务间对话要互相出示身份
        ▼
③ mTLS:从单向信任到双向互认    多出的握手两步 / nginx 双向认证 / 内部 PKI / 零信任
        │ 身份凭证是证书 → 证书从哪来、怎么管、怎么吊销
        ▼
④ 证书的那些事:从 CSR 到过期   X.509 / 信任链 / ACME / CRL·OCSP / 排障手册
```

一句话主线:**代理决定握手在哪儿结束 → 信任从单向走向双向(mTLS)→ 双向信任的载体是证书 → 证书需要一整套 PKI 与生命周期管理**。
